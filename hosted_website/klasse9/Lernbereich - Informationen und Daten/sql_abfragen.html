Übung: SQL-Abfragen

Nutze den SELECT-Spickzettel, um die folgenden Aufgaben möglichst selbstständig in SQLite zu lösen.

  1. Gib alle Daten aus der Tabelle pokemon aus.
    SELECT * FROM pokemon;
  2. Zeige nur die Spalten name_de und kp an.
    SELECT name_de, kp FROM pokemon;
  3. Gib alle Pokémon aus, die zur 1. Generation gehören.
    SELECT * FROM pokemon WHERE generation = 1;
  4. Zeige alle Pokémon mit einem Angriff größer als 100.
    SELECT name_de, angriff FROM pokemon WHERE angriff > 100;
  5. Suche alle Pokémon, deren Name mit B beginnt.
    SELECT name_de FROM pokemon WHERE name_de LIKE 'B%';
  6. Finde alle Pokémon, deren Name auf saur endet.
    SELECT name_de FROM pokemon WHERE name_de LIKE '%saur';
  7. Zeige alle Pokémon, die nicht legendär sind und mehr als 80 KP haben.
    SELECT name_de, kp FROM pokemon WHERE ist_legendaer = 0 AND kp > 80;
  8. Sortiere alle Pokémon nach ihrer Initiative absteigend.
    SELECT name_de, initiative FROM pokemon ORDER BY initiative DESC;
  9. Sortiere alle Pokémon zuerst nach Generation und dann nach KP.
    SELECT name_de, generation, kp FROM pokemon ORDER BY generation ASC, kp DESC;
  10. Zeige zu jedem Pokémon den deutschen Namen sowie typ_1 und typ_2 an.
    SELECT name_de, typ_1, typ_2 FROM pokemon JOIN typen ON pokemon.typen_id = typen.typen_id;
  11. Finde alle Pokémon vom Typ Feuer, egal ob Erst- oder Zweittyp.
    SELECT name_de, typ_1, typ_2 FROM pokemon JOIN typen ON pokemon.typen_id = typen.typen_id WHERE typ_1 = 'Feuer' OR typ_2 = 'Feuer';
  12. Finde alle Pokémon, die gegen Wasser schwach sind.
    SELECT name_de, typ_1, typ_2, gegen_wasser FROM pokemon JOIN typen ON pokemon.typen_id = typen.typen_id WHERE gegen_wasser > 1;
  13. Finde alle Pokémon vom Typ Pflanze, die mehr als 70 KP haben.
    SELECT name_de, kp, typ_1, typ_2 FROM pokemon JOIN typen ON pokemon.typen_id = typen.typen_id WHERE (typ_1 = 'Pflanze' OR typ_2 = 'Pflanze') AND kp > 70;
  14. Finde alle Pokémon, die zur 1. Generation gehören und vom Typ Feuer sind.
    SELECT name_de, generation, typ_1, typ_2 FROM pokemon JOIN typen ON pokemon.typen_id = typen.typen_id WHERE generation = 1 AND (typ_1 = 'Feuer' OR typ_2 = 'Feuer');
  15. Sortiere alle Wasser-Pokémon nach ihrem Angriff absteigend.
    SELECT name_de, angriff, typ_1, typ_2 FROM pokemon JOIN typen ON pokemon.typen_id = typen.typen_id WHERE typ_1 = 'Wasser' OR typ_2 = 'Wasser' ORDER BY angriff DESC;
