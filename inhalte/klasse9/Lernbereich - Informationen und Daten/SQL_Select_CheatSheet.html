SQL Cheat Sheet: SELECT

1. Gesamten Inhalt ausgeben

Mit * werden alle Spalten einer Tabelle angezeigt.

SELECT *
FROM pokemon;

Beispiel: Alle Pokémon mit allen gespeicherten Informationen anzeigen.

2. Nur ausgewählte Spalten anzeigen

Du kannst gezielt nur bestimmte Spalten auswählen.

SELECT name_de, kp, angriff
FROM pokemon;

Beispiel: Zeigt nur den deutschen Namen, die KP und den Angriff.

3. Genau eine Bedingung angeben

Mit WHERE kannst du Ergebnisse filtern.

SELECT name_de, generation
FROM pokemon
WHERE generation = 1;
Wichtige Vergleichsoperatoren:
  • = gleich
  • != ungleich
  • > größer als
  • < kleiner als
  • >= größer oder gleich
  • <= kleiner oder gleich
SELECT name_de, angriff
FROM pokemon
WHERE angriff > 100;

4. Bedingung mit LIKE angeben

LIKE wird für Suchmuster in Texten verwendet.

SELECT name_de
FROM pokemon
WHERE name_de LIKE 'P%';
Platzhalter:
  • % beliebig viele Zeichen
  • _ genau ein Zeichen
SELECT name_de
FROM pokemon
WHERE name_de LIKE '%saur';
SELECT name_de
FROM pokemon
WHERE name_de LIKE '_isa%';

5. Mehrere Bedingungen verknüpfen

Mehrere Bedingungen können mit AND oder OR verbunden werden.

Mit AND

SELECT name_de, generation, ist_legendaer
FROM pokemon
WHERE generation = 1 AND ist_legendaer = 1;

Mit OR

SELECT name_de, typ_1, typ_2
FROM pokemon
JOIN typen ON pokemon.typen_id = typen.typen_id
WHERE typ_1 = 'Feuer' OR typ_2 = 'Feuer';

6. Ergebnisse sortieren

Mit ORDER BY kannst du die Ausgabe sortieren.

SELECT name_de, kp
FROM pokemon
ORDER BY kp ASC;
SELECT name_de, kp
FROM pokemon
ORDER BY kp DESC;
SELECT name_de, generation, kp
FROM pokemon
ORDER BY generation ASC, kp DESC;

7. Fremdschlüssel einer anderen Tabelle nutzen

In der Tabelle pokemon steht nur die typen_id. Die dazugehörigen Typen stehen in der Tabelle typen.

Dafür braucht man einen JOIN. 
SELECT name_de, typ_1, typ_2
FROM pokemon
JOIN typen ON pokemon.typen_id = typen.typen_id;

Beispiel: Zeigt zu jedem Pokémon auch die Typen an.

SELECT name_de, typ_1, typ_2
FROM pokemon
JOIN typen ON pokemon.typen_id = typen.typen_id
WHERE typ_1 = 'Wasser' OR typ_2 = 'Wasser';

Grundaufbau eines SELECT-Befehls

SELECT spalten
FROM tabelle
WHERE bedingung
ORDER BY spalte ASC;
Reihenfolge beim Schreiben:
  1. SELECT
  2. FROM
  3. WHERE
  4. ORDER BY

Typische Beispiele

SELECT name_de
FROM pokemon;
SELECT name_de
FROM pokemon
WHERE ist_legendaer = 1;
SELECT name_de, angriff
FROM pokemon
ORDER BY angriff DESC
LIMIT 10;
SELECT name_de, typ_1, typ_2
FROM pokemon
JOIN typen ON pokemon.typen_id = typen.typen_id
WHERE typ_1 = 'Pflanze' OR typ_2 = 'Pflanze';
Häufige Fehler:
  • Falscher Tabellenname oder Spaltenname
  • Text ohne Anführungszeichen, z. B. WHERE typ_1 = Feuer
  • = statt LIKE bei Mustern
